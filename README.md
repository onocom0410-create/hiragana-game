# ひらがな あそび

未就学〜低学年の子供向けの、ひらがな学習ミニゲーム集。GitHub Pages で公開している。

**公開URL**: https://onocom0410-create.github.io/hiragana-game/

## アーキテクチャ上の注意点

- **各HTMLファイルは完全に自己完結**(ビルド不要、共有JSファイルなし)。単語データやステージ表などは意図的に複数ファイルに**同じ内容をコピー**して持たせている。
- そのため、以下を変更するときは **関係するファイル全部** を同じ内容に直す必要がある:
  - `WORDS`(単語バンク、59語): `hiragana-shooter.html` / `nurinuri-hiragana.html` / `himitsukichi.html` / `hiragana-farm.html`
  - `STAGES`(ステージ表、1-1〜2-2の出題ルール): `hiragana-shooter.html` / `nurinuri-hiragana.html` / `himitsukichi.html` / `hiragana-farm.html`(クエストの単語選択とマップのマス数に使用)
  - `ZODIAC`(十二支モブロボのSVGデザイン): `hiragana-shooter.html` / `nurinuri-hiragana.html`(バトル相手として使用) / `zodiac-preview.html` / `hiragana-farm.html`(ライバルとして使用)
  - BGM/効果音のWeb Audio実装、ズーム禁止・横画面ロック・LINEバナーの共通スニペットも同様にコピー配置
- 出題の読み上げは`speak(単語)`ではなく`speakQuestion(単語, 空欄位置)`を使う。文字が読めない子でも「さいしょ/さいご/まんなかの もじ」と位置が音声だけで伝わるようにするため(答えの文字そのものは読み上げない)。

## 保存データの方針

- **合言葉「がいぶきょうゆ」**: ユーザーがこの言葉を使うまでは、保存データの形式(reshape)を自由に変更してよい(まだ他者に共有していない前提)。言った後は、既存キーの形を変えず、新規キー追加・既存オブジェクトへのフィールド追加のみに限定する厳格モードに切り替える。
- `hiragana_collection_v1`の`gems`は旧仕様(真偽値)→新仕様(`{total,count}`)への移行を`loadCollection()`内で自動で行っている。旧データを壊さない。

## 既知の制限

- 「を」「ぢ」「づ」の3文字は通常の名詞にほとんど登場しないため、現行のクイズ形式(単語の空欄当て)では出題対象に含められていない。
- 横画面ロックはCSSの`@media (orientation:landscape)`による案内オーバーレイであり、OSレベルでの回転禁止ではない。
- LINEなどアプリ内ブラウザ特有のツールバー/スクロール挙動には`position:fixed`固定 + `visualViewport`実測 + 「ブラウザで開く」誘導バナーで対策しているが、アプリ側の挙動に依存する部分もあり完全ではない。
- ダブルタップズーム防止は、時間・位置に加えて`e.target`(同じ要素へのタップかどうか)も条件にしている。位置だけで判定すると、直後に別のボタンが同じ画面位置に入れ替わった時(例:クエスト完了ボタン→ステージクリアポップアップのボタン)に正当なタップまで誤って抑制してしまうため。
