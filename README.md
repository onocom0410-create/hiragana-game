# ひらがな あそび

未就学〜低学年の子供向けの、ひらがな学習ミニゲーム集。GitHub Pages で公開している。

**公開URL**: https://onocom0410-create.github.io/hiragana-game/

## ページ一覧

| ファイル | 内容 |
|---|---|
| `index.html` | トップページ。各ゲームへのリンク一覧 |
| `hiragana-shooter.html` | ひらがなシューター。単語の空欄に入る文字を選んで手書きし、十二支モブロボの敵を倒す。ステージ制(1-1〜2-2)、⭐ガチャ収集あり |
| `nurinuri-hiragana.html` | ぬりぬりひらがな。クイズに正解してボードのマスを塗っていく。「のんびり」モード(制限時間なし・タイムアタック記録つき。同じ問題で2回間違えると正解を優しく見せて次へ進む)と「バトル」モード(対戦相手と陣地の取り合い、制限時間60秒)がある |
| `kiite-kakou2.html` | きいて かこう。音声認識/手入力で単語をセットし、なぞり書きで練習する(元々あった単体アプリ)。音声認識が漢字表記で返ってくる問題に対応するため、子供向け語彙(約190語)の埋め込み漢字→ひらがな辞書を持つ |
| `himitsukichi.html` | ひみつきち。五十音表レイアウトの文字ずかん、キャラクター育成ずかん(十二支ロボ+ぬりぬりマスコット、計18キャラ、Lv1〜5)、ガチャ(ここからも引ける)、ステージ進捗をまとめて見られるハブ画面。**進捗・成績は読むだけだが、⭐/ガチャ景品/キャラ育成/おきにいりは書き込みも行う** |
| `zodiac-preview.html` | じゅうにし ロボ図鑑。シューターに出てくる十二支モブロボ12種のビジュアル一覧 |

## アーキテクチャ上の注意点

- **各HTMLファイルは完全に自己完結**(ビルド不要、共有JSファイルなし)。単語データやステージ表などは意図的に複数ファイルに**同じ内容をコピー**して持たせている。
- そのため、以下を変更するときは **関係するファイル全部** を同じ内容に直す必要がある:
  - `WORDS`(単語バンク、59語): `hiragana-shooter.html` / `nurinuri-hiragana.html` / `himitsukichi.html`
  - `STAGES`(ステージ表、1-1〜2-2の出題ルール): `hiragana-shooter.html` / `nurinuri-hiragana.html` / `himitsukichi.html`
  - `ZODIAC`(十二支モブロボのSVGデザイン): `hiragana-shooter.html` / `nurinuri-hiragana.html`(バトル相手として使用) / `zodiac-preview.html`
  - BGM/効果音のWeb Audio実装、ズーム禁止・横画面ロック・LINEバナーの共通スニペットも同様にコピー配置
- 出題の読み上げは`speak(単語)`ではなく`speakQuestion(単語, 空欄位置)`を使う。文字が読めない子でも「さいしょ/さいご/まんなかの もじ」と位置が音声だけで伝わるようにするため(答えの文字そのものは読み上げない)。

## 保存データの方針

- **合言葉「がいぶきょうゆ」**: ユーザーがこの言葉を使うまでは、保存データの形式(reshape)を自由に変更してよい(まだ他者に共有していない前提)。言った後は、既存キーの形を変えず、新規キー追加・既存オブジェクトへのフィールド追加のみに限定する厳格モードに切り替える。
- `hiragana_collection_v1`の`gems`は旧仕様(真偽値)→新仕様(`{total,count}`)への移行を`loadCollection()`内で自動で行っている。旧データを壊さない。

## 既知の制限

- 「を」「ぢ」「づ」の3文字は通常の名詞にほとんど登場しないため、現行のクイズ形式(単語の空欄当て)では出題対象に含められていない。
- 横画面ロックはCSSの`@media (orientation:landscape)`による案内オーバーレイであり、OSレベルでの回転禁止ではない。
- LINEなどアプリ内ブラウザ特有のツールバー/スクロール挙動には`position:fixed`固定 + `visualViewport`実測 + 「ブラウザで開く」誘導バナーで対策しているが、アプリ側の挙動に依存する部分もあり完全ではない。
